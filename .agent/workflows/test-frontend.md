description: Run React frontend tests locally
---

This workflow runs the unit and integration tests for the React frontend application using Vitest.

1. Navigate to the client directory
```bash
cd /home/basileking/Bureau/cameroun-tour/cameroun-tourisme/client
```

2. Install dependencies (if not already installed)
```bash
npm install
```

3. Run all tests
```bash
npm run test
```

4. Run tests with coverage (optional)
```bash
npm run test:coverage
```
